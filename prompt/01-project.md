Project Rules — Vinhomes Grand Park Landing Page
Mục tiêu

Xây dựng một Landing Page quảng bá bất động sản cho Vinhomes Grand Park tại thành phố Thủ Đức, TP. Hồ Chí Minh.

Trang phải có giao diện hiện đại, cao cấp, trực quan và phù hợp với lĩnh vực bất động sản.

Công nghệ bắt buộc

Chỉ sử dụng:

HTML5

CSS3

JavaScript thuần

Bootstrap thông qua CDN

Không sử dụng:

Backend

PHP

Python

Node.js

React

Vue

Angular

TypeScript

Database

Build tool

Framework frontend khác

File chính

Mã nguồn chính phải được lưu tại:

index.html


Nếu cần tách CSS hoặc JavaScript thành file riêng thì có thể sử dụng:

css/style.css
js/script.js


Tuy nhiên, dự án phải có thể chạy trực tiếp bằng cách mở index.html.

Ngôn ngữ

Toàn bộ nội dung hiển thị cho người dùng phải bằng tiếng Việt.

Chủ đề

Bất động sản cao cấp, tập trung vào:

Vinhomes Grand Park

Thành phố Thủ Đức

Không gian sống hiện đại

Tiện ích đô thị

Giá trị sống cao cấp

Vinschool

Biệt thự/nghỉ dưỡng

Pháp lý và quy trình tư vấn

Chức năng đăng ký tư vấn: form thu thập thông tin cá nhân, hiển thị popup xác nhận gửi email thành công kèm hình ảnh LIKE ngón tay cái.

Không đưa ra các cam kết pháp lý, tài chính hoặc lợi nhuận đầu tư không có căn cứ.

Nguyên tắc code

Code phải:

Có cấu trúc rõ ràng.

Dễ đọc.

Có comment ở những phần quan trọng.

Sử dụng semantic HTML.

Responsive trên desktop, tablet và mobile.

Không tạo lỗi JavaScript trên console.

Không sử dụng inline JavaScript nếu không cần thiết.

Không sử dụng backend.
